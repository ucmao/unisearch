# 🎯 UniSearch 技能体系全景矩阵 (Skills Matrix)

UniSearch 内置 **13 个专业场景化技能**，覆盖深度业务研报、多源并发采集、音视频解析转写与知识资产沉淀。技能支持通过自然语言意图理解、`@` Mention 快捷菜单以及 `/` 指令高效调度。

---

## 💼 1. 业务场景技能 (Business Skills · 采集 + 自动深度研报)

此类技能专为特定业务场景设计，执行后自动编排**多源并发采集**、**结构化清洗**并调用 AI 引擎生成多维度**深度调研分析研报**。

| 技能名称 | 技能 ID | `@`快捷唤起 | 默认信源平台 | 核心分析维度与目标 | 默认输出 |
| :--- | :--- | :---: | :--- | :--- | :--- |
| **📈 新媒体内容调研** | `marketing-content-research` | ✅ 支持 | 小红书、抖音 | 跨平台拆解热门选题、爆款表达钩子、互动指标分布、高频评论诉求与内容机会 | CSV 明细 + 结构化深度研报 |
| **🛡️ 品牌 GEO 监测** | `brand-geo-risk-monitor` | ✅ 支持 | DeepSeek、Kimi、豆包、千问、元宝、纳米AI、文心一言 | 评估品牌在 7 大主流 LLM 问答中的可见性与回答一致性，识别负面风险线索与引用来源 | CSV 明细 + 风险核验研报 |
| **💼 招聘薪酬调研** | `hr-salary-benchmark` | ✅ 支持 | 智联招聘（可选前程无忧/猎聘/BOSS直聘） | 测算目标岗位市场薪酬水位、城市与经验差异、JD 核心技能要求与定价参考 | CSV 明细 + 薪酬调研简报 |

👉 详细业务规则与字段定义请参阅 [**业务技能设计规范目录**](business-skills/)。

## 💡 调度方式与使用技巧

1. **自然语言直接对话**：
   - 直接输入：“帮我调研一下新能源汽车在小红书和抖音上的热门话题” -> 自动匹配 `marketing-content-research`。
   - 输入：“搜索关于 DeepSeek V3 的最新论文” -> 自动匹配 `academic-search-research`。
2. **`@` Mention 快捷菜单**：
   - 在输入框键入 `@` 符号，即刻弹出常用业务技能与执行工具清单，支持键盘上下键与拼音快速筛选。
3. **斜杠指令 (`/`)**：
   - 输入 `/crawl` 快速开启采集，输入 `/report` 快速基于已有数据生成研报。
