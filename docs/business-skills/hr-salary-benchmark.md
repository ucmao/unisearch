# 招聘岗位薪酬调研 Skill

## 基本信息

- Skill ID：`hr-salary-benchmark`
- 适用部门：人力资源部
- 适用角色：招聘、薪酬绩效、HRBP 和人力资源管理人员
- 目标：基于公开招聘岗位数据整理目标岗位的市场薪酬、地域差异和任职要求，为招聘定价与薪酬讨论提供可追溯的参考。

## 典型使用场景

1. 调研某岗位在指定城市的公开招聘薪资区间。
2. 比较不同城市、经验和学历要求对应的薪资差异。
3. 分析目标公司或竞品公司公开岗位的招聘要求和薪资表达。
4. 在样本充分时估算目标薪酬处于市场样本的相对位置。

以下情况不使用本 Skill：查询个人薪资、获取候选人隐私、代替正式薪酬调查、自动决定员工定薪或作出劳动法律结论。

## 用户输入

### 必填

- 标准岗位名称及常见别名。
- 至少一个目标城市或地区。

### 选填

- 行业、职能、岗位级别、经验范围、学历要求。
- 目标公司或竞品公司。
- 发布时间范围。
- 我方拟定薪资区间，用于内部对标。

缺少城市时必须询问；岗位名称过宽时，应先建议拆分岗位族或级别。

## 当前可用数据源

- 主要数据源：智联招聘，支持岗位搜索和职位详情。
- 当前核心字段：职位名称、公司名称、薪资文本、工作城市、经验要求、学历要求、发布时间、职位描述和来源链接。
- 补充数据源：百度、必应中国、360 搜索、搜狗、头条搜索，用于发现公开招聘页和行业资料。
- AI 问答平台仅用于补充解释或发现线索，不与招聘岗位样本合并计算薪资分位数。

BOSS 直聘和猎聘当前没有专用 Connector，不得写成已接入的数据源。

## 工作流程

1. 建立岗位名称、别名、排除词、城市和级别条件。
2. 展示采集范围，取得用户确认后执行智联招聘岗位搜索。
3. 对有效岗位补采详情，保留薪资原文和来源链接。
4. 去重并标准化岗位、城市、经验、学历和薪资口径。
5. 按城市、级别、经验和公司类型分组统计。
6. 输出样本分布、市场区间和业务建议，并说明数据限制。

## 薪资标准化规则

1. 始终保留薪资原文，不覆盖原始表达。
2. 将明确的月薪区间转换为统一的月薪下限、中点和上限。
3. 对“年薪”“日薪”“时薪”“若干薪”等口径单独标记；只有转换条件明确时才换算。
4. 对“面议”、缺少单位、极端异常或无法解析的薪资，不纳入区间统计，但保留在异常清单。
5. 不默认把奖金、提成、补贴、期权和福利计入固定薪资。
6. 同一公司、岗位和地点的疑似重复职位去重，并记录去重规则。

## 固定分析维度

1. **样本概况**：有效岗位数、无效薪资数、平台、采集时间和过滤条件。
2. **薪资分布**：展示下限、中点和上限的中位数及分位区间；小样本不输出精确分位结论。
3. **地域差异**：在岗位级别和经验条件可比时比较城市差异。
4. **经验与学历**：统计不同要求对应的样本和薪资变化，不将相关性写成因果关系。
5. **岗位层级**：区分初级、中级、高级、专家或管理岗；无法可靠判断时标记为未分类。
6. **公司对标**：在公开样本足够时比较目标公司或竞品公司的招聘薪资及要求。
7. **岗位需求**：从 JD 归纳高频技能、职责和资格要求。
8. **薪酬位置**：只有用户提供我方拟定区间且有效样本充足时，计算其在本次市场样本中的近似位置，并明确不是权威市场 PR 值。

人才供需比需要职位数量之外的候选人或简历供给数据，当前平台不具备该数据，不能生成正式供需四象限。

## 输出物

### 《岗位薪酬调研简报》

包含研究口径、样本质量、薪资区间、城市与经验差异、岗位要求、公司对标、建议和限制。

### 《岗位薪酬样本明细》

通过结果看板和 CSV 导出提供岗位、公司、薪资原文、标准化薪资、城市、经验、学历、发布时间和链接。

### 《招聘定价参考》

根据本次公开样本给出偏保守、市场中位和偏竞争性的参考区间；必须显示样本量、计算方法和适用条件，由 HR 负责人结合内部职级与预算决策。

## 质量与边界

- 所有统计结论必须显示有效样本量和时间范围。
- 不同岗位级别、城市和薪资口径不得未经标准化直接合并。
- 公开招聘薪资可能是区间、总包或引流信息，应作为市场参考而非真实在职薪资。
- 不根据公司、学校、年龄、性别等信息推断个人薪酬或录用结果。
- 当前 Skill 不承诺 BOSS、猎聘多源覆盖、自动异常值修正、权威 PR 值、供需比或 Word/Excel 自动报告。

## 验收示例

用户输入：“调研上海和杭州 3～5 年经验的 AIGC 产品经理薪资，并对比我们拟定的 25k～35k。”

合格输出应包含岗位口径、城市样本量、薪资标准化说明、分布对比、我方区间在本次样本中的近似位置、岗位要求和数据限制。
